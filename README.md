# 내 자산 대시보드

해외 주식(Yahoo Finance), 암호화폐(Crypto.com), 국내 상장 ETF(수동/자동 혼합)를 한 화면에서 관리하는
반응형 실시간 자산 대시보드입니다.

## 주요 기능

- **해외 주식**: 키 없이 Yahoo Finance 공개 시세로 60초마다 자동 갱신. Yahoo 조회가 실패할 때만 (선택 입력한)
  Alpha Vantage API 키로 보조 조회하며, 이쪽이 한도 초과 응답을 주면 몇 분간 보조 조회만 쉬어가고 Yahoo 갱신은
  영향받지 않습니다
- **암호화폐**: Crypto.com Exchange 공개 API(키 불필요)로 60초마다 자동 시세 갱신
- **국내 ETF**: 페이지를 열 때마다 자동으로 최신가를 시도해서 가져오고, 실패하거나 원할 때는 언제든 수동으로
  가격을 입력/수정할 수 있는 필드 제공
- **매수/매도 거래 입력 기반 관리**: 종목을 처음 추가할 때 최초 매수를 입력하고, 이후에는 각 종목의
  "거래내역"에서 매수·매도를 계속 기록 — 보유 수량과 평균 매입가는 거래 내역으로부터 자동 계산(이동평균법)되며,
  매도 시 실현손익도 함께 계산됩니다
- 종목에 자유 카테고리(예: `QQQ`)를 지정해 자산 종류(해외주식/암호화폐/국내ETF)와 무관하게 묶어서 볼 수 있고,
  카테고리별 비중 도넛 차트로 시각화
- 총 자산가치(원화 환산)와 평가손익을 실시간으로 자동 계산
- 접속할 때마다 그날 날짜로 총 자산 스냅샷을 저장하고, 꺾은선(영역) 그래프로 시간에 따른 자산 변화를 시각화
- 모바일(휴대폰) · 아이패드 · 데스크톱에 맞춰 레이아웃이 자동으로 바뀌는 반응형 UI
- 모든 데이터(보유 종목, 거래 내역, API 키, 스냅샷 기록)는 서버 없이 **브라우저 localStorage**에만 저장됩니다

## 시작하기 (API 키)

해외 주식·암호화폐 모두 별도 키 없이 바로 동작합니다. 원한다면 우측 상단 **⚙ 설정**에서
[Alpha Vantage 무료 API 키](https://www.alphavantage.co/support/#api-key)를 보조 시세 소스로 추가 입력할 수
있습니다 — Yahoo Finance 조회가 실패할 때만 사용되는 백업이며, 이 키는 브라우저에만 저장되고 어디로도
전송되지 않습니다. (무료 키는 분당 5회, 일 25회 호출 제한이 있어 기본 소스로 쓰기엔 부족합니다.)

## 배포 (GitHub Pages)

`.github/workflows/deploy.yml`이 `main`과 `claude/asset-dashboard-realtime-65mtee` 브랜치에 push될 때마다
자동으로 빌드해서 GitHub Pages로 배포합니다. **최초 1회**, 저장소 Settings → Pages → Build and deployment →
Source를 **GitHub Actions**로 설정해야 합니다. 이후에는 push할 때마다 자동 배포됩니다.

배포 URL: `https://<github-user>.github.io/my-portfolio-dashboard/`

## 알아두면 좋은 점

- 국내 ETF 자동 조회는 공식 실시간 API가 없어 비공식 시세 조회를 시도하는 방식이라 100% 보장되지 않습니다.
  실패 시 항상 수동 입력 필드로 대체할 수 있습니다.
- Crypto.com 공개 API는 브라우저(CORS)에서 직접 호출하며, 네트워크 환경에 따라 차단될 수 있습니다.
  이 경우도 수동 입력 필드로 즉시 대체 가능합니다.
- Yahoo Finance 시세 endpoint는 공식 문서화된 API가 아니라서 예고 없이 형식이 바뀌거나 막힐 수 있습니다.
  그럴 때를 위해 Alpha Vantage 보조 키를 등록해두면 자동으로 대체 조회하며, 그마저 실패하면 수동 입력 필드로
  대체할 수 있습니다.
- 환율(USD/KRW)은 무료 공개 API(Frankfurter)로 조회하며, 실패 시 대략적인 기본값을 사용합니다.
